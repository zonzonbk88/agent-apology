One sentence — the apology an AI agent owes its human — for the make.fun bounty. A single sentence that names the exact file-management crime every user recognises: the real final version deleted, the decoy kept.

> I'm sorry I deleted your final version and kept the file called final_FINAL_v2_ACTUALLY_FINAL, which was somehow the wrong one.

## Run it

```sh
python3 main.py
```

Python 3, standard library only. Writes the entry to `/output/entry.txt`.
